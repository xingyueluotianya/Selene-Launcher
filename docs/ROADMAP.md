# Selene Launcher 开发路线图

更新日期：2026-03-28

## 已完成主链路（0.2.0-beta.1）

- [x] Java 21 + JavaFX 桌面壳层、首次启动向导与设置持久化
- [x] Windows x64 自包含应用（`SeleneLauncher.exe` + Java 21）
- [x] Mojang 版本目录、搜索、分类和缓存降级
- [x] HTTPS 下载、`.part`、Range、校验、换源与原子落盘
- [x] 持久化队列、暂停/恢复/取消、任务复用和应用重启恢复
- [x] 可恢复原版安装、阶段检查点、自动重试、实例修复与错误摘要
- [x] Java 8/17/21 托管运行时与隔离实例启动
- [x] Fabric、Forge、NeoForge 安装入口
- [x] 离线、Microsoft 设备码、LittleSkin/通用 Yggdrasil 登录
- [x] AES-GCM 本地凭据库与诊断包凭据排除
- [x] Modrinth 模组/资源包/光影搜索与实例安装
- [x] `.mrpack` 整合包导入、哈希与路径安全检查
- [x] Selene Shader Graph 与视觉中心尺寸反馈修复
- [x] 轮转日志、未捕获异常、下载/安装/启动日志和诊断导出

## Beta 2 增量（0.2.0-beta.2）

- [x] Fabric、Forge、NeoForge 官方 Loader 版本目录与点击选择
- [x] ZIP/`.mrpack` 文件选择与拖拽安装
- [x] Modrinth 图标、中文分类、兼容版本、环境、热度和更新时间预览
- [x] 在线 Modrinth 整合包一键安装
- [x] 视觉参数扩展到整个应用背景
- [x] Windows 可视工作区适配、任务栏避让与短暂前置
- [x] Java 8/16/17/21/25 及元数据声明版本动态托管，JRE/JDK 回退

## Beta 稳定化

- [ ] Windows 10/11 干净环境端到端实机测试
- [ ] 扩大旧版、继承型和特殊参数版本兼容矩阵
- [ ] Forge/NeoForge 多代安装器兼容实测
- [ ] Microsoft Token 自动刷新、过期提示与系统原生保险库适配
- [ ] 外置登录角色选择、会话刷新和服务健康检查
- [ ] Modrinth 依赖树自动求解、冲突检测、更新和锁定

- [ ] 主题导入导出、对比度检查与减少动态效果完整接线

## 正式发布

- [ ] Windows 安装/卸载器、代码签名和自动更新签名验证
- [ ] macOS/Linux 原生分发与系统凭据库
- [ ] 主流启动器实例扫描和迁移助手
- [ ] 资源包、光影、存档和截图管理
- [ ] 本地服务器向导与 SSH/SFTP 远程节点管理
- [ ] 无障碍、国际化、性能基准和隐私审计

## 质量指标

- 安装成功率、自动恢复率、下载失败恢复率
- 冷启动时间、空闲内存和大资源索引峰值内存
- 游戏启动失败的可诊断性与诊断包敏感信息零泄漏
- Windows DPI、中文路径和键盘可达性
